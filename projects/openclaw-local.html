OpenClaw Local

A self-hosted AI assistant stack for my home lab. One service handles chat, finance, nutrition, a calendar and a system monitor behind HTTPS, and an agent can use my own custom skills to do real work.

How the pieces fit

Internet

Traffic comes in over HTTPS.

Traefik

Terminates HTTPS with Let's Encrypt certificates through DuckDNS, asks for basic auth, adds security headers and compresses responses. Routes by path to the hub.

Hub (one FastAPI service)

Serves the landing page, chat, finance, nutrition, calendar, monitor and heartbeat modules from a single process, with SQLite databases inside it. I merged several small services into this one for speed and simplicity.

OpenClaw agent

Calls the hub's API to run skills, read data and act.

Models

A local Qwen model on llama.cpp, plus hosted models through Google AI Studio and OpenRouter.

What's inside the hub

  • /chat A chat page with streaming replies, file upload, tool calls and multi-model routing.
  • /finance A personal expense and income tracker with credit cards and budgets.
  • /nutrition A calorie and macro tracker with food search across USDA and Open Food Facts.
  • /calendar Google Calendar events, a weekly digest and automatic token refresh.
  • /monitor A dashboard for CPU, memory, disk, GPU and container health.
  • /heartbeat A poller that lets the agent act on its own when something needs attention.

Local models and routing

I started by running a Qwen model locally with llama.cpp on my RTX 4070, which is great for privacy and works offline. For stronger reasoning, faster replies and a longer context window, the chat module can route a request to a hosted model instead.

A keyword-based classifier decides which one to use. Everyday chat goes to Gemini 2.5 Flash, and anything that looks like code, such as code blocks, "debug" or "refactor", goes to Qwen3-Coder through OpenRouter.

Custom skills

The agent has nine custom skills. Adding another is a folder with a SKILL.md file.

  • self-admin
  • calendar-assistant
  • finance-tracker
  • nutrition-tracker
  • ph-credit-card-maximizer
  • ph-investment-advisor
  • travel-advisor
  • media-downloader
  • epub-downloader

Keeping it healthy

The stack starts with one docker compose up. Tests cover the routers, the finance and nutrition databases and their APIs, and GitHub Actions runs them on every push and pull request. Secrets stay in a .env file that is never committed.
